# Inactive synchronization wire reader

This reader is the exact qualified three-language v3 candidate source. It is compiled into the shared Neptune Core used by Windows standalone and portable bundles, but no runtime transport or planner calls it yet.

It enforces received UTF-8 bytes, duplicate keys, Unicode scalar validity, bounded depth and pages, exact int64 counter strings, explicit binding, full descriptors, availability and contiguous feed items. A parsed shape grants no server authority, source completeness, current remote state, baseline adoption or conditional-write permission. Cursor signing, actual lease enforcement and consistent snapshot/feed transport remain separate gates.

The same qualified golden and boundary inputs are consumed by Saturn TypeScript and Pluto Go. The historical qualification labels in golden bytes are retained unchanged.
